# Agent instructions

## Interactive explanations in T3 Code

Use an inline HTML view when interaction helps explain a structure, compare
alternatives, or explore relationships.

1. Build one self-contained HTML document with inline CSS and JavaScript. Follow
   the T3 tool descriptions for layout and theme variables; keep the page
   background transparent and the layout responsive.
2. Check the document with `html_preview` at desktop and narrow widths. Inspect
   the screenshots and console output, exercise its controls, and fix layout or
   interaction errors before publishing.
3. Publish the checked document with `html_render`, using its measured content
   height within the tool's supported range.
4. Keep the final text to information the view does not already convey.

When these tools are unavailable, present the explanation in Markdown.
